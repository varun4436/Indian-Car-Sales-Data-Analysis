Indian Car Sales Data Analysis Dashboard Using Power BI

Project Overview:
This project is based on Indian Car Sales Data Analysis using Power BI. The main objective of this project is to analyze car sales trends, 
understand market performance, and create interactive dashboards for business insights through data visualization.

The analysis includes:
Brand-wise sales analysis
Revenue and profit insights
Monthly sales trends
Top-selling car models
Regional sales performance
Customer and market insights
Interactive dashboard visualizations

This project was created using Power BI along with data analysis and visualization techniques to generate meaningful business insights.

Objectives:
Understand Indian car sales trends
Analyze brand and model performance
Identify important business insights
Create interactive dashboards and reports
Practice real-world business intelligence and data visualization

Dataset Information:
Dataset Name: Indian Car Sales Dataset
File Format: PBIX
Tool Used: Power BI
Dashboard Type: Interactive Sales Dashboard

Dataset contains:
Car Brand Information
Sales Data
Revenue Details
Regional Sales Records
Monthly Sales Trends
Customer Insights
Market Performance Data

Tools & Technologies Used:
Power BI
Data Visualization
Dashboard Design
Data Cleaning
Business Intelligence

Steps Performed:
Imported car sales dataset into Power BI
Cleaned and transformed the data
Created relationships between tables
Built interactive visualizations and KPIs
Designed dashboard layouts
Analyzed sales trends and insights
Generated meaningful business reports

Visualizations Included:
Brand-wise Sales Dashboard
Monthly Sales Trend Analysis
Revenue and Profit Charts
Regional Performance Dashboard
Top-selling Models Analysis
Interactive KPI Cards

Key Insights:
Some car brands generated higher sales revenue.
Monthly sales trends showed seasonal fluctuations.
Regional analysis highlighted high-performing markets.
Interactive dashboards improved sales monitoring and reporting.
KPIs helped identify business growth opportunities effectively.

Conclusion:
This project helped in understanding sales analytics and improved practical knowledge of dashboard creation and data visualization using 
Power BI. It also provided experience in handling real-world sales data and generating actionable business insights.
